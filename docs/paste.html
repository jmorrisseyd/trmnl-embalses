Los seis bloques de la configuración del plugin, en orden. Generado desde src/ el 07/09/2026.

Dos cosas que fallan si se hacen a ojo. El cuadro «Form Fields» quiere una lista YAML tal cual: no añadas una línea custom_fields: encima. Y el marcado no lleva <div class="view">: lo pone el editor.

- keyname: reservoir_ids
  name: Embalses
  field_type: multi_string
  description: Ids de embalses.net separados por comas, en el orden que quieras verlos. El id es el número de la URL, así que embalses.net/pantano-871-rules.html es 871.
  help_text: Ejemplo:&nbsp; 871,795,830
  default: "795,830,816,799"
- keyname: chart
  name: Gráfico
  field_type: select
  description: Qué gráfico de embalses.net mostrar cuando hay un solo embalse seleccionado. Anual compara con los dos años anteriores y la media de 10 años; Histórico son medias mensuales desde 1960; Entradas son los caudales de entrada por mes. Gráficos de Embalses.net, CC BY 4.0.
  help_text: Entradas no existe para todos los embalses.
  options:
    - Ninguno
    - Anual
    - "Histórico"
    - Entradas
  default: ninguno
- keyname: heading
  name: Título
  field_type: string
  description: Texto de la barra inferior.
  default: Embalses
- keyname: footer
  name: Pie (con varios embalses)
  field_type: select
  description: Qué resumen mostrar bajo la lista.
  options:
    - España
    - Conjunto
    - Ninguno
  default: espana
